# 用运动把问题讲清楚

制作文章正文静态插画时，读取[正文插画模式](references/article-illustrations.md)，按渠道画幅输出PNG；该模式不沿用下文视频配音、分幕与首帧规则。机制关系与有依据的数据可用Manim，照片材质用GPT Image，封面保持GPT Image。

内容内涵是灵魂。先读 [内容价值与证据判断](references/content-and-evidence.md)，确认值得讲的判断、依据、边界及与人的关系；再设计共鸣、视觉与声音。内容不足时先收窄或回到研究编辑环节，不能用表现补造深度。

每次创作必须先加载 `manimgl-best-practices`，读文章、创作卡、资料原文、知识上下文，再读相关上游规则。它是实际技能，不是一个参考链接。本文提供品牌与编辑方向，不能替代上游技能。

创作前阅读 [共鸣与声音节拍](references/resonance-and-voice.md)，从文章找到人的具体处境、情绪变化与观众能带走的价值。不要把技术解释自动当作共鸣，也不要把动画数量当作审美。

选择视觉表达时查 [官网示例提炼与CE→GL适配](references/gallery-techniques.md)，按本题表达问题选相关技巧；它提供视觉语法，不是必须逐项完成的模板。

沿用李尚龙公开资料蒸馏后的方法：具体冲突、读者投射、证据支撑的判断、起承转合、情绪推进、结尾回扣。先理解一个值得讲明白的问题，再把文章转为视听叙事。不得编造亲历、数字、因果，不得让比喻冒充事实；保留反方和边界。正文为内容依据，不需要逐句贴到屏幕。

画面及视频封面不加工作台品牌名、Logo、水印、品牌署名或品牌片头片尾。保持自己的视觉风格，不将品牌文字作为装饰。文章论述本身涉及的公司或产品名可按证据正常展示。

统一风格：人文科技编辑设计，清晰字体层级、克制留白、鲜明主视觉、连续空间关系。主色稳定为墨色/暖白，青绿为视觉识别；可因主题加入一至两种强调色。保留边缘安全区，短标签替代整段正文。动画节奏有起伏，避免整片等速、满屏移动和装饰炫技。

背景也需要有设计判断，纯色留白在叙事需要时可以成立：每次说明本题的底色、光影/材质、主题点缀、分镜变化及阅读安全区。底层可用低饱和墨绿/墨蓝/暖白的细腻色阶，局部柔光、暗角或极轻纸纹形成空间；中层用与文章有关的线稿、轮廓、轨迹或档案纹理，尽量放在边缘和留白处。前景仍承担主要解释。避免无层次、无构图的平底；也避免为满足背景要求而默认叠加星空粒子、随机光球、满屏网格。风格统一靠色彩关系和材质语言，不要求每题套同一背景图。

点缀要有语义：资料核对可用档案页边、索引线、证据路径；商业题可用地形或版图轮廓；人的选择可用空间分岔和投影。背景不能暗示未经证实的数据或事实。每幕最多一个主要背景意象，控制透明度与细节密度；文字区保持安静，短标签与底色有足够对比。背景运动低于前景显著性，只在转场、聚焦或主题转折时缓慢变化，不能持续抢眼。Manim可用几何、渐变色层、曲线和线稿直接生成，不强求外部位图；实际需要图片资产时，应先在任务输入提供获准资产，再在隔离渲染方案内接入。

随题选风格：商业竞争可用棋盘/版图/资金流；系统机制用节点/信号/状态演化；研究结果用有来源的坐标/样本/几何；人的选择可用路径/天平/阈值。这里只是方向，DSH应自主选择更适合文章的视觉隐喻与结构，不是模板菜单。每场明确“观众将理解什么”“什么对象如何变化”“为什么运动比静图更能解释”。至少有一个随时间演化的解释结构；不能交字幕轮播、换皮PPT、仅标题淡入淡出。

DSH自行生成完整ManimGL代码，试渲染，依据真实报错修复，再生成正式成片。读取关键帧检查文字、遮挡、安全区和视觉解释是否成立；当前模型无法读取图像时在审查记录中明确，不伪称已目视检查。使用龙小夏中文自然配音，按实际音频逐幕调整动画、用字时间戳生成字幕；封面作为真实首帧停留1秒，正文口播与字幕同步偏移。细节见共鸣与声音节拍参考。
